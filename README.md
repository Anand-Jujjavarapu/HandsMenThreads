1 Project Overview
HandsMen Threads is a Salesforce solution for a fashion business that manages customers, products, orders, inventory, and marketing campaigns. The project brings operational data into one platform and applies automation to improve customer communication, stock control, loyalty management, and order processing.
The implementation combines custom objects, custom fields, lookup and master detail relationships, formula fields, validation rules, profiles, roles, permission sets, email templates, record triggered flows, scheduled automation, Apex triggers, Batch Apex, and Scheduled Apex.
Main Business Outcomes
•	Send an automatic confirmation message when an order is confirmed.
•	Update customer loyalty status from purchase history.
•	Notify the inventory team when stock falls below the defined threshold.
•	Calculate order totals and deduct stock when confirmed orders are processed.
•	Process inventory updates in bulk through scheduled Apex.
