## 1. Project Overview

**HandsMen Threads** is a Salesforce solution designed for a fashion business to manage customers, products, orders, inventory, and marketing campaigns.

The project centralizes operational data on a single Salesforce platform and uses automation to improve **customer communication, inventory control, loyalty management, and order processing**.

### Key Implementation Areas

The solution combines:

- Custom Objects and Custom Fields
- Lookup and Master-Detail Relationships
- Formula Fields
- Validation Rules
- Profiles, Roles, and Permission Sets
- Email Templates
- Record-Triggered Flows
- Scheduled Automation
- Apex Triggers
- Batch Apex
- Scheduled Apex

### Main Business Outcomes

- **Automated Order Confirmation:** Sends an automatic confirmation message when an order is confirmed.
- **Customer Loyalty Management:** Updates customer loyalty status based on purchase history.
- **Low-Stock Notifications:** Notifies the inventory team when product stock falls below the defined threshold.
- **Order & Inventory Processing:** Calculates order totals and deducts stock when confirmed orders are processed.
- **Bulk Inventory Processing:** Uses scheduled Apex to process inventory updates efficiently in bulk.
